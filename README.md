# Présentation MOWATHAQ

Présentation web autonome, générée depuis les sources `src/` puis assemblée en un unique `dist/index.html`.
Les polices et les styles sont intégrés en base64 : le fichier fonctionne hors ligne, sans CDN.

## Commandes

```bash
npm install
npm run build
```
